# 慢慢来 · 个人生活仪表盘

一个粉色与奶油色的温柔小空间，记录每天的一点进步。只使用 HTML、CSS 和原生 JavaScript，不需要安装任何软件、依赖或数据库，也不调用外部 API。离线也可以使用。

## 如何预览

1. 将本仓库下载并解压到电脑上的一个文件夹。
2. 确保 `index.html`、`style.css` 和 `script.js` 放在同一个文件夹。
3. 双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 打开即可。

修改文件后，保存并刷新浏览器即可看到变化。不需要终端、Node.js、Python 或构建命令。手机布局也已适配。

## 如何使用

- **每日待办**：输入一件小事，点击「添加」或按 Enter。勾选方框表示完成；点击右侧的 × 删除。进度条和概览会同步更新。
- **学习记录**：点击「开始专注」启动正向计时，可以暂停、继续；点击「结束并记录」才会计入今日学习时长。不满一分钟也会记录秒数，概览显示完整分钟。忘记开计时器时，可以输入 1–1440 的整数分钟并点击「记录」补记。计时器会保存开始时间，刷新或关闭后再次打开仍能恢复；运行期间关闭页面也会继续累计时间。跨天的计时在结束时计入结束当天。
- **习惯花园**：点击喝水、阅读、运动或早睡卡片打卡，再次点击即可取消。下方显示最近七天的打卡数量，四个习惯全部完成时会开出一朵小花。
- **心情日记**：选一个 Emoji，写下一点感受，点击「保存心情」。也可以只记录心情或只写文字。修改后需要再次保存。
- **每日语录**：按照本地日期每天切换，来自网站内置的温柔语句，无需联网。

## 数据与隐私

数据存储在当前浏览器的 `localStorage`（键名为 `manmanlai-dashboard-v1`），不上传到任何服务器。每天的待办、学习时长、习惯和心情分别保存；新的一天会显示新的空白记录，最近七天的习惯可以直接查看。当前版本没有历史日记浏览与数据导出功能。

请尽量使用同一个浏览器、同一个浏览器用户和同一个文件位置打开。换浏览器、移动文件、使用隐私模式或清理浏览器数据，都可能导致记录不可用或丢失。不同浏览器对直接打开的本地文件存储规则有所差异；如果出现保存失败提示，请检查浏览器设置。数据不会自动同步到其他设备。请勿在此保存唯一的重要资料。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构、导航和功能区域 |
| `style.css` | 配色、卡片、动画和手机适配 |
| `script.js` | 待办、计时器、习惯、心情及本地保存 |
| `README.md` | 中文预览和使用说明 |

想改变配色，可以从 `style.css` 顶部的 `:root` 变量开始；想更换语录或习惯，可以编辑 `script.js` 顶部的 `quotes`、`habits` 数组。保留习惯 ID 可继续使用原有打卡记录。

网站支持键盘操作、可见焦点、屏幕阅读器提示和系统「减少动态效果」设置。页面字体使用系统字体，没有外部字体、图片或脚本依赖。
